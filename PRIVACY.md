# Данные и сетевые запросы yunagi

Дата описания: 9 ноября 2026 года.

yunagi не содержит аналитики, рекламы и системы пользовательских аккаунтов. Разработчик не получает настройки, заметки, задачи и загруженные обои через отдельный сервер yunagi.

## Что остаётся в браузере

В локальном хранилище расширения Chrome сохраняются настройки, избранные сайты, заметка, задачи, выбранный город и его координаты, собственные изображения и видео. Последний прогноз и результат проверки обновлений кэшируются локально. Эти данные не синхронизируются с аккаунтом Google средствами yunagi. Открытые вкладки одного профиля получают изменения через Chrome Storage API.

Экспорт создаёт JSON с настройками, адресами сайтов, заметкой, задачами и пользовательскими медиа. Такой файл может содержать личные данные: его передача другому человеку раскрывает содержимое копии. Расширение само никуда его не загружает.

## Внешние сервисы

- Open-Meteo Geocoding получает текст поиска города. После выбора сохраняются его название и координаты.
- MET Norway получает координаты выбранного города для прогноза. Местоположение устройства не запрашивается.
- Google Favicon получает домены избранных сайтов для загрузки значков; изображения могут приходить с доменов gstatic.com. Загрузку значков можно отключить в настройках избранного. Собственный символ или изображение заменяет внешний значок.
- GitHub (raw.githubusercontent.com) получает запрос manifest.json стабильной ветки для проверки версии, результат кэшируется на шесть часов.
- При поиске и открытии закладки браузер переходит к выбранному поисковику или сайту. Текст запроса передаётся поисковику после отправки формы.

Эти сервисы, как при обычном сетевом обращении, видят IP-адрес и служебные данные запроса. Их собственные правила обработки данных определяются соответствующими сервисами.

## Разрешения

`storage` нужен для сохранения настроек. `unlimitedStorage` позволяет хранить собственные обои и видео локально. Разрешения доступа к хостам ограничены геокодером, сервисом прогноза и GitHub. Расширение не запрашивает историю посещений, геолокацию устройства, доступ к страницам сайтов или cookies.

Для полного удаления локальных данных удалите расширение через Chrome. Ранее экспортированные JSON-файлы остаются там, куда вы их сохранили, и удаляются отдельно.
