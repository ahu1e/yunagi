# 夕凪 yunagi

### Тихое место для начала нового дня.

## ✨ Возможности

- **Атмосферная новая вкладка** — обои на весь экран, матовое стекло, плавное появление интерфейса и ненавязчивая анимация.
- **Настраиваемые виджеты** — независимо меняй размер погоды, избранного и часов с датой.
- **Избранные сайты** — перетаскивай для сортировки; используй стрелки для точной перестановки.
- **Свои значки закладок** — эмодзи или символ, цвет иконки либо собственное изображение.
- **Погода** — температура и состояние погоды для выбранного города, °C или °F.
- **Поиск** — Google, DuckDuckGo, Bing, Brave Search или Ecosia.
- **Обои под себя** — загрузи изображение, настрой кадрирование, яркость и затемнение.
- **Автоматические темы** — акценты меняются по времени суток или сезону; можно оставить ручную тему.
- **Режим фокуса** — спрячь виджеты, запиши намерение и собери небольшой список задач на день.
- **Часы при бездействии** — после выбранной паузы время плавно появляется по центру, погода — строкой ниже.
- **Снегопад** — включай снежинки вручную или автоматически зимой; настраивай плотность.
- **Движение фона** — по желанию добавь лёгкий параллакс или собственные видеообои без звука.
- **Резервные копии** — экспортируй и восстанавливай настройки, закладки и локальные медиа из JSON.
- **Локальное хранение** — личные данные и медиа остаются в хранилище Chrome.

## 🚀 Установка

Сборка и дополнительные зависимости не нужны. Скачай проект через **Code → Download ZIP** и распакуй архив. Если проект уже склонирован, переходи к установке:

1. Открой в Chrome `chrome://extensions`.
2. Включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение**.
4. Выбери папку проекта — ту, в которой находится `manifest.json`.
5. Открой новую вкладку.

После изменений в файлах нажми **Обновить** на карточке расширения и открой новую вкладку заново.

## ⚙️ Настройки

Нажми шестерёнку внизу справа, чтобы открыть общие настройки. Двойной клик по виджету открывает его собственную панель.

| Раздел | Настройки |
| --- | --- |
| **Погода** | Город, единицы измерения, размер виджета |
| **Избранное** | Название, адрес, порядок, символ/эмодзи, цвет или изображение значка |
| **Часы и дата** | Формат времени и размер |
| **Фон и атмосфера** | Яркость, затемнение, кадрирование, акцент и тема вручную / по времени / по сезону |
| **Часы при бездействии** | Выключено, 30 секунд, 1, 2, 5 или 10 минут без действий |
| **Движение фона** | Параллакс и собственные видеообои MP4/WebM размером до 15 МБ |
| **Сезонное настроение** | Ручной снегопад, плотность и автозапуск с декабря по февраль |
| **Резервная копия** | Экспорт и импорт файла настроек JSON |

### Режим фокуса

Нажми кнопку с глазом или клавишу `F`. Виджеты исчезнут, а в центре появится компактное пространство для заметки-намерения и списка задач. Данные сохраняются локально. Нажми `F` или `Esc`, чтобы вернуться.

После двух минут бездействия часы и погода показываются по центру экрана. Интервал можно изменить или отключить в общих настройках; любое движение мыши, нажатие клавиши или прокрутка возвращают обычный вид.

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `/` | Перейти в строку поиска |
| `Enter` | Выполнить поиск |
| `F` | Включить или выключить режим фокуса |
| `Ctrl + ,` | Открыть общие настройки |
| `Esc` | Закрыть меню/настройки или выйти из режима фокуса |

## ❄️ Сезонные эффекты

Снег рисуется локально на canvas: без сетевых запросов и без перекрытия элементов интерфейса. Его можно включить вручную, выбрать редкую, обычную или плотную частоту либо включить автоматический режим на декабрь—февраль. При системном уменьшении анимации снежинки остаются неподвижными.

Автоматическая тема подбирает акцентные цвета под время суток или сезон. Параллакс и видеообои **выключены по умолчанию**. Видео воспроизводится без звука; для него доступны MP4 и WebM.

## 🌤️ Погода и приватность

Для прогноза погоды используется [MET Norway](https://api.met.no/), а для поиска координат введённого города — геокодер [Open-Meteo](https://open-meteo.com/). Город указывается вручную — расширение **не запрашивает геолокацию**. Для погоды нужен интернет.

Аналитики и телеметрии нет. Закладки, заметки, задачи, настройки и загруженные медиа хранятся локально в Chrome. Сеть используется только для запроса погоды и для перехода на выбранный сайт или поисковик.

## 🧩 Технологии

- Chrome Extension Manifest V3
- HTML, CSS и нативный JavaScript — без фреймворков и сборщика
- Chrome Storage API для пользовательских настроек
- Canvas API для снегопада
- MET Norway Locationforecast и Open-Meteo Geocoding API для погоды

## 🛠️ Если что-то не работает

- **Новая вкладка не обновилась:** нажми **Обновить** на странице `chrome://extensions` и открой новую вкладку.
- **Нет погоды:** проверь интернет и написание города; запроси обновление в настройках виджета.
- **Видео не запускается:** используй MP4 или WebM, не больше 15 МБ; воспроизведение без звука необходимо для автозапуска Chrome.
- **Не импортируется копия:** используй JSON-файл, созданный кнопкой экспорта yunagi.
