# Выпуск yunagi

Расширение не требует сборки для работы. Инструменты ниже нужны только разработчику.

## Проверки

1. Node.js 22+ и pnpm 11.25.0: `pnpm install --frozen-lockfile --ignore-scripts`.
2. `pnpm run check` — манифест, файлы, иконки, синтаксис и проверки логики.
3. `pnpm exec playwright install chromium` — тестовый браузер на Linux/macOS. На Windows браузерный тест по умолчанию использует установленный Chrome. Для другого исполняемого файла задайте `CHROME_PATH`.
4. `pnpm run test:browser` — изолированный профиль, локальный сервер, реальные клики и клавиатура, три размера окна. Внешние ответы погоды, города, обновлений и фавиконов заменены фикстурами: тест не проверяет доступность провайдеров и не отправляет личные данные.
5. `pnpm run release` — повторяет check и создаёт `dist/yunagi-<version>.zip` и SHA-256. В архив входят только runtime-файлы и assets; тесты, документация и зависимости исключены.

GitHub Actions выполняет эти же проверки, браузерные сценарии и упаковку. Скриншоты находятся в `.test-artifacts/`, артефакты CI хранятся 14 дней.

## Что проверено автоматически

- Изменённые поля настроек, вложенные правки, обновления между вкладками на уровне Storage API, ошибка записи и повторная попытка.
- Импорт, допустимые диапазоны, нулевое затемнение, выключенная подпись, оформление и кадрирование.
- Фикстурный прогноз, кэш и отказ сети; выбор города вместе с регионом.
- Редактирование значков, меню избранного, удаление и восстановление, лимит сайтов.
- Перетаскивание, изменение размера, отмена и выход из конструктора; реальное движение мышью и клавиатурой.
- Окно прогноза и фокус; отсутствие горизонтального переполнения на 1440, 800 и 390 px; сохранение заметки и задач после перезагрузки.

## Перед публикацией

Браузерные UI-тесты открывают страницу с CSP манифеста через локальный HTTP-сервер. Это не заменяет проверку установленного расширения и реальной сети.

- Установить содержимое релизного ZIP как распакованное расширение в чистом профиле Chrome; проверить страницу ошибок расширения и открыть несколько новых вкладок.
- Проверить реальные MET Norway, Open-Meteo, GitHub и фавиконы, затем повторить открытие без сети.
- Проверить собственные JPG/PNG/WebP и MP4/WebM, выключение и повторное включение видео, экспорт и импорт копии с медиа.
- Проверить одновременные изменения в двух вкладках. При конкурентном редактировании одного поля или целого списка действует последняя запись; совместное редактирование отдельных элементов списка не реализовано.
- Проверить обновление поверх предыдущей версии с существующими данными. Экспортировать копию до обновления.
- Перед новым релизом поднять `version` в manifest.json; собрать ZIP заново. Не изменять файл проверки версии в main раньше готовности релиза.
- Для Chrome Web Store подготовить скриншоты, описание и опубликованную ссылку на PRIVACY.md. Загрузка в магазин, публикация и проверка модерацией в этой работе не выполнялись.

## Локально выполнено 9 ноября 2026

Проверки логики и браузерные сценарии пройдены в установленном Chrome на Windows. Скриншоты настроек, погоды и фокуса просмотрены. ZIP проверен отдельным ZIP-ридером. Последний набор подтверждений фиксируется при финальном запуске проверок; CI запустится после push.

Дополнительная локальная проверка: накопление снега, столкновение падающей снежинки с виджетом, перемешивание в центре с сохранением объёма и сбрасывание за край реальным движением мыши, ограничение высоты и числа частиц, очистка слоя и уменьшение анимации. Runtime-модуль `snow-drifts.js` включается в релизный архив.
